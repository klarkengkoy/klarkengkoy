## A little background

I previously built Android apps at Software Ventures International, where I also maintained existing apps and migrated legacy Java code to Kotlin. I then worked at Accenture supporting EMM/MDM partner engineers on Google's Android Enterprise platform. I used my Android development experience to reproduce reported issues, investigate API behavior, and review device bug reports.

I'm now studying Japanese and building personal apps with Kotlin and Jetpack Compose. The portfolio brings together those projects and my earlier work in Android development and support.
